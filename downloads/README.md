# Freelance calculator downloadable templates

These files are static, free resources for planning a quote before using the browser calculator.

- `freelance-quote-inputs.csv` — copyable input checklist for pricing assumptions.
- `freelance-quote-scope-template.md` — scope/payment-terms checklist for a private project folder.

Do not add client names, bank details, tax IDs, contracts, invoice images, personal data or confidential business information to public GitHub Issues.
